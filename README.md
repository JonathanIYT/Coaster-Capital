# Coaster Capital

**Coaster Capital** is a free browser-based theme park auction card game built with HTML, CSS, and JavaScript.

Players take control of **JonathanIYT World**, a theme park trying to outbid rival operators and build the strongest attraction lineup across five operating seasons. Each round brings a new auction card to the table, including roller coasters, dark rides, food stands, water rides, family attractions, and park upgrades.

The goal is simple: spend wisely, build strategically, survive maintenance costs, and finish with the highest park value.

## How the Game Works

Coaster Capital is played in two main phases:

### Auction Phase

A new attraction card appears on the table. Players bid against three AI-controlled rival parks. Each card has different strengths, including:

- Thrill
- Nostalgia
- Capacity
- Theme
- Food
- Maintenance cost

Winning a card adds it to your park board, but every purchase also reduces your available cash.

### Event Phase

At the end of each season, an event card appears. Events represent different park conditions, such as coaster enthusiast weekends, heat waves, rainy days, food festivals, heritage weekends, and opening day crowds.

Players choose one attraction to feature during the event. The featured card earns revenue based on how well its stats match the event. Food stands, capacity, and upgrades can also support the whole park through bonus scoring.

## Features

- 3D-style card game presentation
- Single-player gameplay against AI opponents
- Three difficulty levels: Easy, Medium, and Hard
- Five-season game structure
- Unique auction cards with no duplicate auction lots
- Coasters, dark rides, food stands, water rides, family rides, and upgrades
- Event-based scoring system
- Whole-park support bonuses
- Maintenance costs
- Final rankings screen
- Confetti celebration when JonathanIYT World wins
- Original browser-generated background music
- Fully playable as a single `index.html` file

## Rival Parks

You compete against three AI-controlled park operators:

**Apex Amusements**  
A thrill-focused rival that aggressively chases major coaster cards.

**Heritage Grove**  
A nostalgia-focused park that values historic rides and classic attractions.

**Metro Parks Group**  
A corporate-style operator that prioritizes capacity, infrastructure, and safe investments.

## How to Play

1. Press **Start Game**.
2. Choose a difficulty.
3. Bid on attraction cards during auctions.
4. Pass when a card becomes too expensive.
5. Build your park board.
6. Choose your best attraction during each season event.
7. Earn revenue, pay maintenance, and continue through five seasons.
8. Finish with the highest final score.

## Hosting

This game is designed to run directly in the browser. No install is required.

To host it with GitHub Pages:

1. Save the game file as `index.html`.
2. Upload it to a GitHub repository.
3. Open the repository settings.
4. Go to **Pages**.
5. Deploy from the `main` branch.
6. Share the generated GitHub Pages link.

## Project Goal

Coaster Capital was created as a fun theme park strategy game for coaster fans, amusement park history fans, and viewers who enjoy documentary-style theme park content. The game mixes auction strategy with the kinds of decisions real parks face: balancing big thrill rides, classic attractions, guest demand, food revenue, capacity, and maintenance costs.
